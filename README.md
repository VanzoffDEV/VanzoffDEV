# 🚀 Sobre Mim

Minha jornada na tecnologia começou em uma sala de aula de **robótica**, onde descobri o poder de transformar lógica em movimento.  
Naquela época, atuei como **monitor da turma**, desenvolvendo habilidades de liderança e mentoria técnica.

Hoje, sou estudante de **Análise e Desenvolvimento de Sistemas (ADS)** e fundador da **Agência Vanzoff**, focando em:

- 🌐 Criação de aplicações web performáticas com **React + TypeScript**.
- 📈 Estratégias digitais voltadas para crescimento de negócios.
- ⚡ Desenvolvimento Full Stack com foco em experiência e performance.
